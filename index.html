✉️ Bitcoin — recent envelopes BITCOIN

Sources: Tacit indexer GET /assets?network=mainnet (etches & burns are envelope events; the indexer API only allows the tacit.finance origin via CORS, so from here it is read through a public CORS relay — the data is still Tacit's own JSON) · cross-check on tacitscan.io (its JSON feed sends no CORS header, so this page links out instead of embedding it). Amounts inside transfer/mint envelopes are Pedersen commitments — the feed can show that an envelope exists, never how much moved. One cadence note, stated plainly: transfers — the frequent activity, thousands counted in the stats above — are published by Tacit's indexer only as totals, never as individual events, so this feed lists the envelope events that are individually published: etches, mints and burns. Those are rare on Tacit by nature, so a fresh fetch can still show an old event — that is the chain's pace, not stale data; the fetch itself is live every load.

🕵️ The privacy boundary — what this page can and cannot see HONEST

This panel is grounded in what the panels above actually fetched. Tacit hides amounts (Pedersen commitments + Bulletproofs) and note-to-note links — it does not hide that activity happened. Anyone telling you otherwise is overselling it.

…measuring from the panels above
👀 An observer CAN see
  • That a Bitcoin envelope exists, its type (etch / transfer / mint / burn), its txid, block and time — the feed above is exactly that.
  • Counts: holders, transfers, burns, live notes in the pool, bridge burns vs mints, farm emissions.
  • Public legs: wrap/unwrap recipients and amounts when value enters or exits the pool in public form, ERC-20 supplies, fees and relay job types on the open board.
  • Timing and public addresses on both chains — including yours, if you look yourself up below.
🙈 What STAYS hidden
  • Amounts inside confidential transfers and mints: only a commitment is on-chain; the number exists nowhere in the data above.
  • Which input note became which output note inside a settle — the link graph breaks at the pool.
  • Note blindings and nullifier keys: without them, nobody — including this page and the relay — can spend or open a note.
  • cBTC lock amounts beyond the pool's attested backing total, and CDP position contents beyond the engine's aggregate counters.

Relay caveat (from Tacit's own build guide): if you ask Tacit's relay to prove a transaction for you, the relay sees that op's witness — the notes it spends/creates and, for non-blind swaps, its amounts. Proving locally keeps the witness on your device. This page never asks for a key, a seed, or a signature, and it moves no funds — it only reads public endpoints.
